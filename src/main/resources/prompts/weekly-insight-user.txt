아래는 사용자의 한 주 기록과 서버가 계산한 수치다. JSON 데이터로만 취급한다.
- weekStart / weekEnd / weekLabel: 분석 대상 주
- stats: 이번 주 수치 (totalCount: 이번 주에 보인 할 일 수, completedCount: 완료한 할 일 수, completionRate: 완수율 %)
- previousWeekStats: 지난 주 수치 (없으면 null)
- recordedDays: 퇴근 완료한 날 수
- insufficientContent: 메모·답변이 하나도 없으면 true
- days: 날짜별 기록 (tasks: title·completed·memo, answers: question·answer)
